This repository is created to practice Git and GitHub fundamentals through hands-on tasks and real-world version control scenarios.

\- Git repository initialization and management

\- Committing changes

\- Pushing changes to GitHub

\- Resolving merge conflicts

\- Maintaining a clean working directory

\## Merge Conflict Practice



In this exercise, two branches modified the same line in `app.txt`.



\- \*\*Feature branch:\*\* `feature/update-status`

\- \*\*Production branch:\*\* `master`



A merge conflict occurred when the feature branch was merged into `master`. The conflict was resolved by preserving both updates.



\### Final Output



```text

Applicaton status: Production Updated

Applicaton status: Feature updated

```
